# Висновки щодо використання методу Монте-Карло для моделювання кидання кубиків

У цьому завданні було змодельовано кидання двох ігрових кубиків 1 000 000 разів за допомогою методу Монте-Карло.

**Порівняння результатів:**
Отримані емпіричні дані практично ідеально збігаються з теоретичними (аналітичними) розрахунками. Різниця між ймовірностями, отриманими методом Монте-Карло, та теоретичними значеннями становить менше 0.05% для кожної можливої суми.

Наприклад (з одного з прогонів):
- **Сума 7** (найімовірніша): Аналітично — 16.67%, Монте-Карло — ~16.68%.
- **Сума 2** (найменш ймовірна): Аналітично — 2.78%, Монте-Карло — ~2.76%.

**Висновок:**
Закон великих чисел працює ідеально. Метод Монте-Карло продемонстрував надзвичайно високу точність при великій кількості ітерацій ($N=1 000 000$). Він є ефективним інструментом для розв'язання ймовірнісних задач, особливо там, де аналітичний розрахунок ускладнений або неможливий.
